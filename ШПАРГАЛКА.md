# Шпаргалка: порядок разработки

Краткий чеклист. Подробности и примеры кода — в [ЗАДАНИЕ.md](./ЗАДАНИЕ.md).

## Подготовка

- [ ] Установить Go, Docker
- [ ] `cp .env.example .env`
- [ ] `make db-up`
- [ ] `go get` все библиотеки (см. ЗАДАНИЕ, Шаг 0.4)

## Код (по порядку!)

- [ ] **config** — Config, getEnv, DSN, Load
- [ ] **database** — Connect
- [ ] **models** — User, Message, RegisterRequest, LoginRequest, SendMessageRequest
- [ ] **auth** — HashPassword, CheckPassword, Claims, GenerateToken, ParseToken
- [ ] **auth_test** — тесты пароля и JWT
- [ ] **repository/user** — New, Create, FindByEmail, FindByID
- [ ] **repository/message** — New, Create, GetRecent
- [ ] **middleware** — extractToken, Auth, GetUser
- [ ] **handlers** — Handler, writeJSON, setTokenCookie
- [ ] **handlers** — Register, Login, Me, GetMessages, SendMessage
- [ ] **handlers/pages** — Login, Register, Chat
- [ ] **handlers** — Routes, WebSocket
- [ ] **hub** — New, Run, Register, BroadcastMessage
- [ ] **hub/client** — ReadPump, WritePump
- [ ] **main.go** — собрать всё
